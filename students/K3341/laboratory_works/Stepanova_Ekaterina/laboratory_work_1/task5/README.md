# Практическое задание 5. Простой веб-сервер (GET/POST)

Здесь уже недостаточно отдавать статический файл — нужно разобрать HTTP-запрос вручную: считать первую строку (GET /path HTTP/1.1 или POST ...), определить метод и путь, а для POST — прочитать тело запроса после заголовков. По методу сервер решает, что делать: сохранить присланную оценку по дисциплине или собрать HTML-страницу со списком всех оценок.

Написать простой веб-сервер для обработки GET и POST HTTP-запросов с помощью библиотеки socket в Python. Сервер должен:

- Принимать и записывать информацию о дисциплине и оценке по дисциплине.
- Отдавать информацию обо всех оценках по дисциплинам в виде HTML-страницы
